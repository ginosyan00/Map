# Sample models

| File | Description |
| --- | --- |
| `sample-building.glb` | Default POC building (~18×12 m footprint, ~24 m tall, ground origin) |
| `office-building.glb` | Same asset, alternate name for upload tests |

Regenerate:

```bash
npm run generate:sample-model
```

In the app: click a building → **Use Sample Model** → **Apply Replacement**.
Or **Upload GLB** and choose one of these files from `public/models/`.
